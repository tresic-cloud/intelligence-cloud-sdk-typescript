# Contributing

Thanks for your interest in the Intelligence Cloud SDK. Tresic maintains this SDK.

## Pull requests

We don't accept code contributions from outside Tresic. Pull requests from outside contributors are closed without being merged, so that all code in the SDK is owned by Tresic and covered by its licence (see `LICENSE`). If you have a fix in mind, describe it in an issue instead.

## Bugs and feature requests

Open a GitHub issue, or write to support@tresic.cloud or your provider. Issues are public, so never include tokens, passwords, API keys, webhook URLs, recording links, phone numbers, names or any conversation content. Include the SDK version, your runtime version, the method you called and the `request_id` from the error.

## Security issues

Don't open an issue. Report vulnerabilities to security@tresic.cloud, as described in `SECURITY.md` and at https://docs.intelligence.cloud/security.

## Feedback

Suggestions and feedback you send may be used by Tresic without obligation to you, as the Intelligence Cloud API and SDK Terms (https://docs.intelligence.cloud/terms/api) set out.
