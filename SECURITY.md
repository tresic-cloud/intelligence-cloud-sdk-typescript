# Security

Please report security vulnerabilities in the Intelligence Cloud SDK for TypeScript privately to **security@tresic.cloud**. Do not open a public issue.

Include the SDK version, a description of the issue and the steps to reproduce it. We acknowledge reports and keep you informed until the issue is resolved.

Our security programme and disclosure policy: https://docs.intelligence.cloud/security

Never include credentials, tokens, recording links or conversation data in a report.
